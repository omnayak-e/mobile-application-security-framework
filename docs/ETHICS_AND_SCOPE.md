# Ethics, Scope and Safe Use

Use only on apps you own or have permission to assess. The framework is a review aid; it is not a replacement for manual testing, MobSF, emulator testing, or backend authorisation checks.

## Before testing
- Obtain explicit written authorisation.
- Define target assets, permitted techniques, test windows, rate limits, and emergency contacts.
- Use a lab or a system you own whenever possible.
- Minimise impact and stop if the test behaves unexpectedly.

## Data handling
- Do not commit sensitive logs, tokens, personal information, or unredacted customer captures.
- Store generated reports securely and redact secrets before sharing.
- Findings should be validated and described accurately; sample data is illustrative, not evidence of a real compromise.

## Reporting
Record the affected asset, observation, evidence, severity rationale, limitations, and recommended remediation.
